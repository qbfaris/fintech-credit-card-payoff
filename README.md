# Programming for FinTech Project 2

## Project Name
Credit Card Payoff Calculator

## Description
This is a Python program that estimates how long it will take someone to pay off a credit card balance. The user enters their current balance, annual interest rate, and monthly payment. The program calculates how many months repayment will take and how much interest they will pay in total.

## FinTech Connection
Credit card debt is a common part of personal finance. This project uses a simple program to help people understand how interest affects the amount they owe. It can help someone make a more informed decision about their monthly payment.

## How to Run
1. Open `FarisMohamedain_credit_card_payoff.py` in Python.
2. Run the program.
3. Enter your balance, interest rate, and monthly payment.
4. Read the payoff summary.

## Notes
The calculator assumes the interest rate stays the same, interest is added monthly, and no new purchases or fees are added. Results are estimates and may differ from a real credit card statement.
